# Little Acorns parent app

Parent app for Little Acorns Academy, a private primary school in Nairobi
(PP1 to Grade 6, about 140 pupils). We have 9 staff and fee income last
year was about KES 4.5 million.

Parents sign up, see their child's term reports and attendance, pay fees
by M-Pesa, and get SMS alerts. Teachers upload class photos.

## Run

    npm install
    npx prisma migrate dev
    npm run dev
